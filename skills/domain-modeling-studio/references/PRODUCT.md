# Domain Modeling Studio

## Platform and stack

Offline web artifact. React Flow with JSON was approved as the first implementation candidate; dependencies are bundled by the skill maintainer, and the recipient opens one HTML without installation or a server.

## Users and job

A developer or domain expert collaborates with a coding agent to understand an existing business flow, distinguish implementation from desired rules, and return attributable feedback. The agent investigates source code; the human edits the proposed flow and comments on the current flow.

## Confirmed scope

Current/proposed switch, diagram at left, evidence and feedback at right. Proposed nodes and edges support direct editing, with undo/redo and saved state. Feedback is copied as Markdown with model JSON. Baseline conflicts protect additional human edits. Outputs are model/evidence records, agreed glossary, Gherkin drafts and implementation candidates. Source citations, AI deductions and human agreements remain distinguishable.

## Visual contract

Operate mode: an unobtrusive Japanese desktop editor, pale canvas, readable system text, native labeled form controls, restrained green primary action, and the supplied EventStorming category colors. Status is also expressed in words. The confirmed two-column review layout stacks on narrow screens. No remote fonts or decorative assets are required. The supplied studio reference is the visual starting point; this skill is not a new brand exercise.
