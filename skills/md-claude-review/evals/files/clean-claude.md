# Billing service

Go monorepo. Run `task test` and `task typecheck` before reporting a change done. Never edit `gen/`: it is regenerated by `task gen` and hand edits are lost.

## Commands

- `task test` runs the suite; `task test -- ./pkg/invoice` runs one package.
- `task lint` runs golangci-lint; `task gen` regenerates `gen/`.

## Conventions

Wrap errors with `fmt.Errorf("...: %w", err)` so callers can use `errors.Is`. PR titles use Conventional Commits because squash merge takes the title as the commit message.

## Gotchas

Integration tests need `POSTGRES_URL`; without it they skip silently and the suite still passes.
